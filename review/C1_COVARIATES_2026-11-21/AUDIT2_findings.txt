c1_covariates_cluster.py has these modes:
- selftest: synthetic data, no project imports.
- export-patients: a local helper that writes the patient list from an inputs npz.
- blind: counts only, plus a listing of the cluster result folders for PS 0 item 7.
- gate (H-V1): columns 0..5 compared with the saved matrix; prints host, max and 99.9th-percentile diff, and PASSED (exit 0) or FAILED (exit 3).
- gate-r20 (H-V2): R20 compared with rna_pcs20 after aligning column signs, tolerance 1e-6.
- export-scores (H0): writes the discovery score TSV with repr floats and '#' header lines.
- arm (A_C3, A_R20, V_C3, V_R20): genes x 1001.
- placebo (--draws a-b): one genes x 51 file per draw; draws already written are skipped.
- manifest: one file covering both cohort folders, with optional not_completed and untestable lines.

How it is built:
- Cases, tested genes, R, P, W and K come from the published c1_run_test.prepare / c1_run_test_luad.prepare, called unchanged with the published flags. The LUAD rule, protein and RNA-manifest hashes are asserted, as in the plex re-read precedent.
- All five frozen modules are hash-checked before import. composition_controls.comp_score and MARKERS are imported as they are. The R20 lines of transcriptome_baseline.py are re-implemented, and the code says so.
- The published permutations are crc32(b"c1_<cohort>|perm") x 1000. Placebo seeds are crc32(b"c1_cov|<cohort>|cap|%02d" % j), and row i of placebo j is row q_j[i] of R20.
- The pool is built like run_pool. The usable-gene filter is the published one and is asserted equal to the saved matrix's gene list. A non-finite value is fatal.
- Outputs go to .partial files with exclusive create and are never overwritten. A run is recorded as attempt 1 or 2; one unchanged rerun is accepted and a third is refused. Each run writes a JSON log.
- Production modes refuse unless the sidecar's hash matches the one given on the command line, every sidecar entry present on the cluster matches, the host equals --pinned-host, and that host has a passed H-V1 record.

The three wrappers are cloned from the plex-reread precedents: the same environment exports, an argument whitelist, -n 8 for UCEC and -n 4 for LUAD. The discovery wrapper uses morpho_env.sh with one BLAS thread.
